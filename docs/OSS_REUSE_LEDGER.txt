WORLD DAYS DECISION
Build a small first-party recurrence engine supporting only:
- fixed date
- Nth weekday
- last weekday
- last day of month
- fixed range
- annual authoritative override
- multiple rules per canonical observance
- explicit unresolved state for lunar/authority-defined cases

This follows App Factory Dependency Admission: do not add a package for stable logic that remains small and testable.
