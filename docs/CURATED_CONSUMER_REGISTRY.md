## Rules

- `OFFICIAL_*` means an institutional authority is directly evidenced by its primary source.
- `RECOGNIZED_NGO` means the observance is created/coordinated by a traceable non-governmental originator.
- `POPULAR` means a traceable originator exists, but the observance is cultural/consumer rather than institutional.
- A record is never upgraded because multiple discovery sources repeat it.
- If an originator changes a date/rule, the canonical record must be reverified before the next dataset release.
